# Talons

Browser terminal for Solana memecoin calls. Public DexScreener and GeckoTerminal data, no worker and no RPC key.

The original Next.js worker (wallet cohorts, KOL stream, shared archive) stays on `main`. This branch is the live terminal.

```bash
npm install
npm run dev
```

Calls, radar, token page, watchlist, and the paper track record. A call is stored in the browser at the market cap when the gate first passes.
